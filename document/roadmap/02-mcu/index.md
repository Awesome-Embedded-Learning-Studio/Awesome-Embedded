# MCU 实践

当前我们把 MCU 教学集中建设在 STM32 路线上。学习者带着基本工具能力和足够的 C 语言能力进入 [ST-Forge](/roadmap/02-mcu/st-forge)。课程终点不提前指定某个综合产品，由实际建设和验证逐步形成。

## 当前主线：ST-Forge

ST-Forge 以 STM32F1 / Cortex-M3 为主要教学平台，课程主轴 2026-10-24 起定为 Cortex-M3 处理器架构。我们从工具链和最小工程出发，一路经过处理器本体、内存系统、异常与中断、启动与时钟、链接与运行时和调试系统，外设在其中作为架构的应用案例出现，最后到 RTOS 的架构视角和收官项目。

课程设计已经做得细致，但实现仍处在早期建设阶段。我们在本站只按已经存在的代码和验证证据描述进度，不把课程目录当作全部完成。

## 周围的支持仓库

这些仓库围着 ST-Forge 转，我们把它们的作用和边界列在下面。它们不是学习顺序。

| 仓库 | 对 ST-Forge 的作用 | 边界 |
|---|---|---|
| [micro-forge](/projects/micro-forge) | 为受支持的 STM32F103 固件提供确定性模拟、故障注入和 CI 入口 | 只覆盖已经实现和回归的 CPU/外设行为，不替代真板 |
| [Tutorial_FreeRTOS](/projects/tutorial-freertos) | 在 Host 上解释任务、队列、同步和调度语义 | 不证明 STM32 上的实时性、移植和外设行为 |
| [Tutorial_AwesomeHardware](/projects/tutorial-awesome-hardware) | 补充读手册、电源、电路、接口和板级调试知识 | 当前 MCU 硬件内容仍在逐步建设 |
| [BareMetal-Drivers](/projects/baremetal-drivers) | 保存可复用的驱动和器件资产 | 可以接收成熟成果，但不是固定下一阶段 |
| [bareline](/projects/bareline) | 展示现代 C++ 如何进入无堆、无异常的 MCU 工程 | 只有被真实的 STM32 工程实际用起来后，才算完成课程交接 |
| [libestdx](/projects/libestdx) | 提供 C++23 的 STM32F103C8T6 器件驱动资产 | 从教程主线解耦出来供取用，仿真验证依赖 Renode，不是课程阶段 |

## 验证怎样逐步晋升

```text
纯逻辑 Host 测试
    → micro-forge 中验证受支持的功能语义与故障
    → STM32F103 真板实验
    → 成熟、可复用的代码资产
```

验证和资产按上面四层晋升，实验不必层层走全，我们也不承诺所有实验都经过完全相同的层次。

模拟器证明指令、寄存器、异常、协议状态机和确定性外设语义，电气、时序、功耗、模拟信号和板级兼容交给真板。我们要求每个实验写清自己实际通过了哪一层。

## 关于综合项目

MCU 路线不预定统一的结课工程。ST-Forge 是否以及怎样形成综合课程项目，以后由已经完成的内容、验证能力和真实需求决定，真到了那一步，我们再在项目目录单独登记。
