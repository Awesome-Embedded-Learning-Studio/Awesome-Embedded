# ST-Forge 规划

## 这个仓库是什么

ST-Forge 是面向 STM32 学习者的开源课程仓。2026-10-24 起课程主轴定为 Cortex-M3 处理器架构，教学板是 STM32F103C8T6 Blue Pill（一块常见的低成本入门板）。叙事立场从"怎么点灯"换成"这颗处理器为什么这样工作"：外设从课程主体降级为架构的应用案例，读者学完带走的是换一颗 Cortex-M 芯片也成立的知识。

课程路线 P0 到 P9 十段：序章与工具链，处理器本体（寄存器组、流水线、指令集），内存系统（内存映射、总线矩阵、位带），异常与中断（硬件压栈、尾链、NVIC），启动与时钟（启动文件逐行、时钟树），链接与运行时（链接脚本、程序的内存形象），调试系统（SWD、断点的实现、周期计数器），外设即架构案例，RTOS 的架构视角（PendSV 与上下文切换），收官项目。ARM 汇编的读与写织在架构线里，目标是读得懂反汇编与启动文件、写得出小段函数，不用汇编写程序。

验证分三层，每个实验标注走到了哪层：电脑上的纯逻辑验证、micro-forge 模拟器仿真、真板实测。配套模拟由 [micro-forge](/plans/micro-forge) 承担，已支持 Cortex-M3 启动、NVIC、SysTick、RCC、GPIO、USART1、TIM2、AFIO、EXTI 的仿真与追踪。

## 现状

本节的数字与事实来自仓库 README 与组织快照，查询日期随文标注。

2026-10-02 的组织快照记录 2 星、1 fork、MIT 许可，贡献者 3 人，仓库开源未归档。仓库自带 VitePress 文档站，GitHub Pages 站在线。

仓库现有可继承的资产：环境搭建教程十四篇（Windows 与 WSL 双线）、一个可编译的 blink 工程（整理为黄金模板 examples/00_blink_cmake 仍在待办）、micro-forge 的模拟支持如上。2026-10-22 清点时仓库顶层还没有 examples/ 目录，firmware/ 公共底座未建。

## 下一代方向

2026-07 定稿的课程矩阵是 P0 到 P7 八阶段，主轴是外设训练。2026-10-24 起课程重开为 P0 到 P9 架构主轴版：已验证的资产（环境教程、黄金模板、模拟器支持）直接继承，课程矩阵与路线文档按新方向改写，旧版矩阵被取代。

第一件事仍是黄金模板归位，它是后续所有章节复制起步的源头，没跑通之前新课程没有可复现的起点。

## 边界与不做的事

- 模拟通过不写成硬件通过。micro-forge 还没实现的外设（ADC、DMA、I2C、SPI、真实 Flash 擦写）不能标记成仿真通过，这些留给真板。
- 课程主线语言是 C，运行时机制带 C++ 对照，C++ 本身不是这门课的主线。
- 外设不养生产驱动：成熟可复用的驱动资产进 BareMetal-Drivers，课程里只做架构验证。
- 本页不承诺日历排期，"近期"指动手的先后，不指日期。
