# PenguinLab 规划

## 这个仓库是什么

PenguinLab 是一个动手实验室，覆盖嵌入式 Linux 与桌面 Linux 的内部机制，从内核一直做到用户空间（仓库 description，2026-10-02 组织快照）。实验全部跑在 QEMU 模拟环境里，支持 ARM32、ARM64、RISC-V、x86_64 四种架构，不需要实体开发板（站内项目目录页与仓库 README）。内容用分层知识图谱组织，中英双语，教程站在线，地址见文末相关链接。

2026 年 10 月 22 日，仓库方向确定升格为内核与操作系统研究板块。工作内容从铺教程改为研究成熟的操作系统，包括研读论文、记录笔记、登记相关新闻，并用 C 或 C++ 复刻其中一部分机制。

现有教程与笔记全部保留，转作研究材料。仓库随后按新结构整体重构，旧内容怎么进入新结构，见下一代方向一节。

## 下一代方向

主推方向是内核与操作系统研究板块，产出单位是研究单元。四样齐了算一份研究单元：一个机制的解释、用 C 或 C++ 写的最小复刻、在 QEMU 上的运行记录、旧材料的映射表。

板块的日常动作是研究成熟的操作系统、研读论文、记录笔记、登记相关新闻，研究单元把这些动作的产出固定成可复核的格式。第一个研究单元选哪个机制，待定，由维护者选题后开工。

转向怎么落到存量上：仓库已有 130 篇教程与 253 篇笔记，研究单元需要的解释与复刻正用得上这批材料。新结构按单元组织，旧内容在单元里逐个建立映射后迁移，不整批搬迁。重构后的目录形态随第一个研究单元一并成形，在此之前不预铺空目录。

## 近期要做的事

先做轻量修正，把数字与徽章改对，再启动第一个研究单元。

- 查清 89、97、130 三个数字各自的出处，README 与进度索引统一到一套数。做完的标志是两处展示同一套数字，每个数字都能对应到仓库里的实际文件或索引字段。
- 把 README 第 13 行的 Docusaurus 3.10 徽章改成 VitePress，版本号按 package.json 写。做完的标志是徽章与站点实际构建工具一致。
- 对外进度按进度索引的实数展示亲测比例，按 7/97 计算。做完的标志是对外页面不再出现拿 130 篇教程总量当分母的完成度说法。

## 边界与不做的事

- 不再新开教程主线，不排定期的教程更新，仓库按研究单元推进，节奏跟选题走。
- 现有教程与笔记保留为材料，随研究单元逐个建立映射后进入新结构，不做一次性整批的目录搬迁。
- 机制复刻限定 C 与 C++，以单个机制的最小可运行为准，不追求覆盖整个内核。
- 本页不代维护者选机制，也不承诺日历排期，"近期"指动手的先后，不指日期。
