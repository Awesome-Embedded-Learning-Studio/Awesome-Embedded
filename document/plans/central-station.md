## 这个仓库是什么

这里是 Awesome-Embedded-Learning-Studio 的中心文档站，也就是本仓库 Awesome-Embedded 本身。站点用 VitePress 搭建，导航与侧栏集中在 project.config.ts 里管理，构建配置读取它生成整站配置，中文是默认语言，英文走 /en/ 前缀。它最初承载仓库目录和学习地图，现在同时是组织的发布位与编排入口：长文和周报在文章区出刊，各仓库的规划页与进行中的方向在这里登记，多个站点联合构建的入口后续也落在这里。

## 现状

以下事实截至 2026-10-23，证据来自仓库提交记录、站内目录盘点与各页面本身。

- 站点是配置驱动的 VitePress 文档站，构建配置含 SEO、OG 与 sitemap，导航与侧栏由 project.config.ts 统一定义。英文侧目前只有首页加一篇博客译文，是骨架状态。

- 项目目录 33 页，其中 ZerOS、libestdx、devtree-journey 三页是新上线的。学习地图按四支柱组织（基础、MCU、Linux、专项），工作流文档 5 篇，贡献指南、维护者说明、组织排名各 1 页。

- 博客机制已上线。文章列表自动生成，支持标签分区与 RSS 订阅，文章头补齐了日期与标签。周报并入文章区，停刊前三期（2026-06-16、2026-07-02、2026-07-20）已迁入并打「周报」标签，旧 /weekly/ 路径的指路页已删除。文章区现有 5 篇内容，两篇长文加三期周报。

- 周报在 2026-07-20 那期之后停刊，至今约三个月，复刊时间未定。

- 「路线与进行中」页（/todo/）上线，登记方向级事项，与项目规划页互为索引。

- 全站可读性与导航改版完成：正文提到 16px，学习入口提前到首屏，窄屏用文字版学习树。

- 构建参数化完成。base 路径与站点 origin 从写死改为可配置，本地可以换环境构建，sitemap 与 RSS 的域名跟随配置取值。

- 仓库首次提交在 2025-12-07，以 MIT 许可发布，GitHub Pages 部署使用 actions/deploy-pages。线上是否已部署最新构建，待核实。

## 下一代方向

中心站的工作分六条流：博客化、可见性与热更新、新叙事落站、构建债清理、联合发行、GitHub 侧整理。博客化与构建债清理已经完成，成果收在上面的现状里。剩下四条与待定项如下。

### 可见性与热更新

组织随时可能出现新仓库、仓库转公开这类变化，靠人工记录会丢。方向是在周报发布流程里加一步变化清单检查，当期没有处理的变化留痕保留，下一轮数据采集不会把它们冲掉。长线目标是公开数据变化后自动重建并部署中心站，构建失败时保留上一份可用页面。

### 新叙事落站的收尾

三个新仓库的项目页已上线，剩下的收尾件有这些。视频导航只留一个指向 aels-prism 的入口，aels-prism 公开后补入口。学习地图里 GUI 归属的旧句子按 visor 与 vesper 的新口径改写。启动入口脚本与学习地图的仓库清单对账保持通过。已下线项目在站内的旧足迹已清干净（页面、路线图与导航图数据）。

### 联合发行

组织里的仓库和站点在变多，克隆、构建、发布需要统一编排。方向是产出一份仓库与产物清单，以及可复现的内部构建验证报告，内容包含锁版本、隔离构建、挂门户、链接检查，逐仓记录仓库地址、输入 ref 与 SHA、构建命令、产物目录与目标 base 路径。已完成的构建参数化是这条的前置。完整发行维持三条门槛：教学仓文档站补齐，visor、vesper、bootflint、aels-prism 四个仓全部公开（公开后补入口），aels-prism 稳定运行三期。门槛不因内部原型降低。

### GitHub 侧整理

GitHub 组织首页 README 与各仓库简介按新口径改写，与站内保持一致，按使用频率分批做。aex 相关的旧说法一并收敛，组织盘点（2026-10）显示它实际只有两个消费处。

### 待定项

- 联合构建的内部验证是否先行，先行的话首验选哪两个公开站。

- 周报复刊从哪个区间起算，停刊空档要不要补一篇回顾。

- visor、vesper、bootflint、aels-prism 四个仓的公开时点。

## 近期要做的事

- 周报复刊，带上变化清单跟踪。验收口径是复刊一期以「周报」标签的文章出刊，期内新仓库的可见性信息完整，上一期未处理项在新一轮采集后仍可查。

- 新叙事收尾清查。验收口径是视频导航只剩指向 aels-prism 的一个入口，学习地图旧口径句改完，启动脚本对账检查保持通过。

- 联合构建首次内部验证，待定项确定后动工。验收口径是两个公开站的验证报告可复现，逐仓字段完整。

- GitHub 侧口径统一。验收口径是组织首页 README 与活跃仓简介和站内一致，抽查无旧口径残留。

## 边界与不做的事

- imx-forge、rk-forge、h618-forge 三个 forge 是独立产品，不合并，不抽公共模板，各自的规划在自己的规划页里。

- GUI 框架线归 visor，桌面线归 vesper，Cinux-Base 并回 Cinux 主仓。中心站不新造说法，只按这个归属改写旧句子。

- 完整发行的三门槛不降低，具体见上文联合发行一节。

- 英文站维持骨架，中文内容稳定后再做 1:1 翻译，暂不排英文工作量。

- MicroWatch 不纳入 AELS，站上不建它的项目页，也不链接它的 Pages 站。esp-forge 已取消。

- 本页只写方向与边界，不承诺任何更新节奏。
