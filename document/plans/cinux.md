# Cinux 线规划

## 这个方向是什么

Cinux 线由两个仓库组成。Cinux 主仓是 x86_64 操作系统实验产品，用现代 C++17 从 Bootloader 一路实现到图形桌面，内核、用户态、文件系统与图形栈全链路自研，定位是实验载体，用来快速验证新的设计与系统能力。Cinux-Book 是主仓的教学版，把已经稳定的能力整理成中文教程。重放指按主仓的稳定版本或提交号把能力重新实现并验证一遍，读者因此能从零跟完整条操作系统开发链路，配套的在线教程站已上线。

两仓分工是主仓负责实验，Cinux-Book 负责教学重放。主仓的变更不要求每次都同步展开成教程，教程也不追逐前沿变化，只选择稳定下来的能力讲解。

## 现状

本节的数字与事实来自 2026-10-02 与 2026-07-20 两份组织快照、两仓 README 与学习地图，日期随文标注。

Cinux 主仓在 2026-10-02 快照里记录 42 星、9 fork、主语言 C++、MIT 许可证，最近一次提交是 2026-08-23。仓库 README 的功能清单包含 113 个系统调用、SMP 多核、TCP/IP 协议栈、用户态 GUI 桌面（GUI host 进程、Widget 工具包、多终端）与 GCC 自举，提供预编译镜像一键运行和 GDB、VSCode 两种调试模式。路线图按 Feature 与 Milestone 组织，规划为 13 个 Feature、约 50 个 Milestone。进度另有按站计数的内部记录，2026-10-15 核对时第 19 站已收官，站与公开 Milestone 编号的对应关系待核实。

Cinux-Book 在同一份快照里记录 56 星、3 fork，2026-10-02 当天仍有推送，是当期组织快照里最活跃的仓库。教程按十个阶段递进，从 MBR 与 Bootloader 讲到内存管理、进程调度、用户态与系统调用、文件系统，最后到 GUI 桌面与多进程，Ubuntu 24.04 的默认编译器即可构建（据仓库 README）。

星数在两个多月里的变化（07-20 快照对照 10-02 快照）：主仓从 31 到 42，Cinux-Book 从 44 到 56。

同一组对照还记录了一次组织结构调整。07-20 快照里存在 Cinux-GUI 与 Cinux-Base 两个仓库，10-02 快照里两者都已不在组织仓库列表。Cinux-GUI 已删除。Cinux-Base 的定位曾是 Cinux 的基础组件仓（07-20 快照的仓库描述），它的 freestanding 基础类型与容器（不依赖标准库运行环境的基础组件）如今作为主仓内部代码维护，这与学习地图第四支柱的公开写法一致。

## 下一代方向

主推方向保持主仓激进实验在前、教学重放在后。GUI 线的去向按新表述移交。

主仓的实验定位是有意选择的。新设计与新系统能力先在主仓快速验证，验证稳定后再进入教程，这条路径让实验不被教学节奏拖住。下一个主线切片的主题由维护者自选，本页不预设。

通用 GUI 框架线由 visor 承接。框架要跨宿主运行（宿主指程序运行所在的平台），目标宿主覆盖裸机小屏、Cinux 与桌面，Cinux 只是宿主之一。面向 Cinux 的桌面壳由 vesper 承接，它用 visor 的框架能力给 Cinux 做可拖窗口的桌面。两仓尚未公开，公开后补入口。

为什么这样分。框架要在多种宿主上运行，放在单一操作系统的仓库里，其他宿主的使用者难以参与，所以独立成 visor。桌面壳直接服务 Cinux 的桌面体验，开发节奏与框架本身不同，所以另立 vesper。两仓用途不同，不互相合并。主仓已经交付的 GUI 桌面代码留在原地，变化只在后续演进的归属。

以下事项尚未确定，登记为待定项。

- 主仓下一个主线切片的主题与范围，由维护者选定后更新本页。
- visor 与 vesper 的公开时间，公开后在本页与项目目录补入口。

## 近期要做的事

- 主仓推进下一个主线切片，主题由维护者自选。做完的标志是新能力进入一次版本发布，发布说明写清在 QEMU 里的复现步骤。
- Cinux-Book 跟随该切片出教学重放。做完的标志是教程站新增对应章节，配套代码按稳定版本或提交号在 Ubuntu 24.04 默认编译器下完整构建并运行。
- 修公开页面里 GUI 去向的旧表述。主仓 README 目前仍链接已删除的 Cinux-GUI，相关句子按 visor 与 vesper 的新去向改写，Cinux-Book 的 README 与项目页一并核对。做完的标志是公开页面不再有指向已删除仓库的链接，读者能从两仓公开页面查到 GUI 线的去向。

## 边界与不做的事

- 双轨合并的议题不复存在。Cinux-GUI 已删除，关于它并回主仓还是继续双轨的讨论随之结束，"双轨有意存在"与"Cinux-GUI 重写成自己的操作系统"两种旧说法作废，公开文字不再沿用。
- visor 与 vesper 是两个用途不同的仓库，不互相合并，也不并回 Cinux 主仓。
- freestanding 基础组件作为主仓内部代码维护，不再单设 Cinux-Base 仓库。
- Cinux-Book 不追逐主仓的每次前沿变化，只选择稳定下来的能力做教学重放。
- 主线内容的选择权在维护者，本页只登记方向，不替内容排期，不承诺日历时间。
