# Issue Board

A board of open issues across the org's repositories, fetched live from GitHub's public API in your browser. Grouped by repo by default, with a toggle for time order. Only open issues are listed, and sub-issues load on demand when you expand a card. Follow the title to GitHub for the full body and discussion.

Anonymous API calls are limited per IP (search: 10/min, sub-issues: 60/hour). If a request fails, the board says why and when the quota resets.
