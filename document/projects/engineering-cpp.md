## 简介

engineering_cpp 是 B 站《现代 C++ 工程实践》的配套 hub：用 C++23 与统一 CMake 工程，把语言知识放进可以构建、测试和演进的小项目里，讲共同的需求、设计、测试、构建和交付方法。

第一季课程已经完结，后续内容按 hub-and-spoke 结构发展：横向工程能力留在本仓，具体专题放进独立仓库深入。

## 核心内容

- ArgParser、FileCopier、DirScanner 等贯穿工程方法的小项目
- Catch2、CI、ASan/UBSan 等工程质量工具
- 通过 submodule 串联 SimpleIniParser 与 anatomy_memory 两个专题仓

## 前置知识

- 基本 C++ 语法
- CMake 基础
- 支持 C++23 的编译器

## 与 AELS 的关系

属于教学线「C++ 工程实践」分组，是[学习地图](/roadmap/)第一支柱从语言到工程的桥梁：组织 [Tutorial_cpp_SimpleIniParser](/projects/tutorial-cpp-simple-ini-parser) 与 [anatomy_memory](/projects/anatomy-memory) 两个 spoke，语言基础来自 [Tutorial_AwesomeModernCPP](/projects/tutorial-awesome-modern-cpp)。
