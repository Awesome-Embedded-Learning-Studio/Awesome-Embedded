## 简介

`engineering_cpp` 是 B 站《现代 C++ 工程实践》的配套 hub，使用 C++23 与统一 CMake 工程，把语言知识放进可以构建、测试和演进的小项目中。

仓库已经公开，第一季 46 期视频已完结，后续内容继续按 hub-and-spoke 结构发展。

## 核心内容

- ArgParser：命令行参数解析
- FileCopier：文件操作、进度显示与性能测量
- DirScanner：目录扫描与 Top-K 分析
- Catch2、CI、ASan/UBSan 等工程质量工具
- 通过 submodule 串联 Tutorial_cpp_SimpleIniParser 与 anatomy_memory

## 项目关系

`engineering_cpp` 负责横向工程能力和新手入口；IniParser 与 anatomy_memory 作为独立专题仓继续深入。ModernCPP 讲语言与原理，本仓负责把这些知识组织成工程。

## 前置知识

- 基本 C++ 语法
- CMake 基础
- 支持 C++23 的编译器
