## 简介

基于 QEMU 的 Linux 内核学习站：用分层知识图谱组织内容，在 ARM32 / ARM64 / RISC-V / x86_64 多架构模拟环境中动手实践内核原理、驱动开发与嵌入式全栈，无需物理开发板。

内容建立在真实的学习笔记与可编译代码示例之上，覆盖内核子系统、设备驱动、BSP、调试调优与虚拟化，支持中英双语。图谱规模、笔记数量与所基内核版本持续演进，以仓库为准。

## 前置知识

- C 语言编程
- 操作系统基本概念
- Linux 命令行操作

## 与 AELS 的关系

属于教学线「系统与硬件基础」分组，是系统基本功承重墙：把知识陈述变成可运行、可观察的实验。它为 [imx-forge](/projects/imx-forge) 与 [rk-forge](/projects/rk-forge) 提供通用 Linux 深度，但不是进入具体开发板的强制门禁——可先学，也可在板级实践中按需回补。
