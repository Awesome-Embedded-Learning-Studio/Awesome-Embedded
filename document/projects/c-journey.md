## 简介

C-Journey 是 C 语言的进阶学习日志与社区枢纽：目标不是「会写 C 语法」，而是逐步具备用 C 完成真实工程、库设计、系统编程与嵌入式开发的能力。

它把 C 进阶拆成八个阶段，从开发环境与基础工具一路走到综合项目与开源协作，每个阶段配套知识点文档、示例与练习。各阶段的当前覆盖范围与细节以仓库文档为准。

## 路线概览

开发环境与基础工具 → C 语言基础 → 指针、内存与数据布局 → 数据结构与算法基础 → 工程化与模块化设计 → 系统编程 → 嵌入式 C 与硬件开发 → 综合项目与开源协作。

## 与 AELS 的关系

属于教学线「工具与语言基础」分组，是[学习地图](/roadmap/)第一支柱的 C 语言承重墙，与 [Tutorial_AwesomeModernCPP](/projects/tutorial-awesome-modern-cpp) 互为补充——前者打 C 工程地基，后者攻现代 C++。阶段后期的嵌入式 C 内容自然衔接 [ST-Forge](/projects/st-forge) 等 MCU 实践。
