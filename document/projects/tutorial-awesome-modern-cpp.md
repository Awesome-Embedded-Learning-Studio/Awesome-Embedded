## 简介

体系化的现代 C++ 系统教程，按十卷组织，从 C 语言基础一直覆盖到 C++23：语言特性、标准库、工程实践与领域应用整合为一条完整学习路径，并针对嵌入式学习者设置了 STM32F1 实战环节。

配套 VitePress 文档站支持中英双语；示例代码以 CMake 工程组织、可在 CI 中编译验证，不是文章里的孤立片段。

## 前置知识

- 基本编程概念（变量、循环、函数）
- 命令行基本操作

## 与 AELS 的关系

属于教学线「工具与语言基础」分组，是[学习地图](/roadmap/)第一支柱的 C++ 语言承重墙。它为 C++ 工程实践（[engineering_cpp](/projects/engineering-cpp)）与产品组件（[QuarkWidgets](/projects/quark-widgets) 等）提供语言基础。
