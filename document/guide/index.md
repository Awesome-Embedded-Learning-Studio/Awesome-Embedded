# 我该从哪里开始？

不管你是第一次来还是老朋友，先按"你知道多少"对号入座，找到自己的起点。完整学习路径见 [学习地图](/roadmap/)，挑仓库见 [项目一览](/projects/)。

## 按经验分层

| 你是这种人 | 起步入口 |
|---|---|
| **零基础小白**：没怎么写过代码，"嵌入式"是啥都不太清楚 | [P0 核心起步](/roadmap/01-fundamentals/)。先过 EmbedBox（工具）和 C-Journey（C 语言），不碰硬件也能学。 |
| **有编程底子，初碰嵌入式**：PC 上写过 C / C++，但没摸过开发板 | [P0](/roadmap/01-fundamentals/) 核心过一遍，然后按兴趣选 [P1 单片机](/roadmap/02-mcu/) 或 [P2 嵌入式 Linux](/roadmap/03-linux/)。 |
| **一边熟，想扩另一边**：玩过单片机（STM32 / Arduino）或 Linux（树莓派）之一，想补另一个 | 缺哪边进哪边。MCU 熟 → [P2](/roadmap/03-linux/)；Linux 熟 → [P1](/roadmap/02-mcu/)。[P0](/roadmap/01-fundamentals/) 按需补。 |
| **嵌入式老手**：两边都玩过，想钻深、做产品、或贡献 | 可以直接参与积极建设的 [Cinux 独立线](/roadmap/04-specialty/)，查看已经定稿的 [rk-forge 三板路线](/roadmap/03-linux/rk-forge)，或进入 [贡献指南](/contributing/)；其余专题暂处规划阶段。 |

## 按你想做啥

分层是按"你知道多少"。再按"你想做啥"挑一条：

- 想做 IoT 传感器节点或 USB / 无线设备 → [esp-forge（ESP32-S3）](/roadmap/02-mcu/esp-forge)
- 想做边缘 AI 盒或智能屏 → [rk-forge](/roadmap/03-linux/rk-forge)
- 想做嵌入式桌面产品 → CFDesktop（正在建设的产品形态层，见 [P2](/roadmap/03-linux/)）
- 想自己造个 OS → [Cinux 独立线](/roadmap/04-specialty/)
- 想吃透 RTOS → [P0 的 FreeRTOS](/roadmap/01-fundamentals/)（上位机就能学，不用板子）
- 只想随便逛逛仓库 → [项目一览](/projects/)
